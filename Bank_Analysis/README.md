# Bank Loan Analysis Dashboard

A Power BI data analysis project for exploring bank loan applications, loan performance, and risk indicators through an interactive dashboard.

## 📌 Project Overview

This project analyzes more than **38,000 loan applications** using Power BI, and DAX.

The dashboard focuses on:
- Loan application activity
- Loan performance
- Loan status and risk indicators
- Key financial metrics
- Interactive exploration of the available loan data

## Key Features

- Analysis of 38K+ loan applications
- Interactive Power BI dashboard
- DAX measures for analytical KPIs
- Loan performance analysis
- Risk-focused metrics
- Interactive filtering and dashboard exploration

## Key Finding

The analysis identified a **13.8% bad-loan rate** within the analyzed loan portfolio.

The dashboard allows users to interactively explore the loan data and investigate patterns related to loan performance and risk.

## Technologies

- **Microsoft Power BI** — data modeling, visualization, and dashboard development
- **DAX** — calculated measures and analytical metrics

## Dashboard Metrics

The dashboard includes analysis of:
- Total loan applications
- Loan application volume
- Loan performance
- Bad-loan rate
- Other calculated measures derived from the available dataset

DAX measures are used to calculate and present analytical metrics consistently across dashboard filters.

## Power BI Dashboard

The Power BI dashboard provides an interactive interface for exploring the loan portfolio. Users can filter and compare available loan information to investigate application patterns and loan performance.
